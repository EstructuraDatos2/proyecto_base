# Propuesta de videojuego para Proyecto Final ED2
Nombre del Juego:
- Lights Out

## Descripción
Lights Out es un juego de rompecabezas en el que tenemos una cuadricula con "focos o luces" que encienden y apagan, el rompecabezas se resuelve cuando se apagan todos los focos.

El jugador puede interactuar con un foco, este foco cambia de estado (encendido/apagado) y a su vez cambia el estado de los focos adyacentes tanto vertical como horizontalmente.

El juego termina cuando se apagan por completo todos y cada uno de los focos de la cuadricula.

## Objetivos
- El juego inicia con una configuración resolvible aleatoria de focos encendidos.
- Se debe crear un sistema para seleccionar el foco que cambiará de estado.
- Se puede configurar el tamaño de la cuadricula.
